# NOVA TYPE

Школьный тренажёр скорости печати: практика на RU / EN, библиотека учебных текстов, задания, результаты, личный прогресс, рейтинги и единая административная панель.

## Локальный запуск

1. Скопируйте `.env.example` в `.env` и укажите PostgreSQL, длинный `NEXTAUTH_SECRET` и начальный пароль администратора.
2. Установите зависимости: `npm install`.
3. Подготовьте базу: `npx prisma db push`.
4. Создайте администратора: `npx prisma db seed`.
5. Добавьте стартовые учебные тексты: `npm run db:seed-texts`.
6. Запустите проект: `npm run dev`.

Приложение откроется на [http://localhost:3000](http://localhost:3000).

## Готовый MVP

- вход по username/password без обязательной смены выданного пароля;
- Time 15/30/60/120, Words 10/25/50/100 и Text режимы;
- RU / EN, отдельный typing engine, WPM, raw WPM, accuracy и ошибки;
- блокировка paste/drop, учёт потери фокуса и очередь подозрительных результатов;
- result screen, личный рекорд, история, профиль, уровень, streak и график;
- рейтинг класса, школы и классов по среднему WPM ученика, с периодами и фильтром RU / EN;
- создание классов и учеников, редактирование, архив, удаление, просмотр пароля, общий Excel со всеми логинами и паролями и журнал действий;
- библиотека из 48 стартовых текстов для 1–8 классов с фильтрами по языку и сложности;
- задания для классов, автоматическая фиксация выполнения и подробная статистика класса;
- олимпиады для 5–7 классов: зал ожидания, ручной или запланированный старт, два автоматически созданных текста и две синхронные попытки с выбором лучшего результата, защита от вставки, победители по параллелям, командный рейтинг классов, дисквалификация, проекторное табло, PDF-дипломы и Excel-экспорт;
- русский интерфейс;
- preview импорта `.xlsx` / `.csv` и экспорт аккаунтов;
- адаптивный dark UI по Stitch-концепции NOVA TYPE.

Функции учителя объединены с ролью Super Admin. Daily Challenge исключён из продукта по решению заказчика.
